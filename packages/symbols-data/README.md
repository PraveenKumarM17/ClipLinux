# Symbols data

Curated offline catalogs for `clipl-symbols`. Not a complete Unicode dump.

| File | Contents |
| --- | --- |
| `symbols.json` | Practical symbols by category |
| `kaomoji.json` | Text faces / kaomoji |

Update by editing the JSON (keep glyphs as UTF-8 strings) and running
`cargo test -p clipl-symbols`.
